# Lazy-Netbox

### Netbox_UI_Homepage_like_Google.user.js
New vision of Netbox homepage.

Work with [Tampermonkey](https://www.tampermonkey.net/) extension. Change "https://demo.netbox.dev" in **@namespace** and **@match** to your site for work.

**Alt + M** - show full menu structure

**Ctrk + K** or **/** - goto search

**Alt + Z** - back to original
